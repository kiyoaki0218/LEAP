 見出し：よし 《良し・善し》 （ク活用） ［重要度：★★☆］
 訳語 ：①【よい。すぐれている。】 ②【〔「よき人」の形で〕身分が高く教養がある。】
 ーーー
 核  ：「よし→よろし→わろし→あし」
 解説 ：「よし」は絶対的に良い評価を表す語であるのに対し、「よろし」は「欠点はあるが悪くはない」というほどの、そこそこの評価を表します。「よき人」といった場合は「身分が高く教養のある人」の意を表します。
 入試 ：入試で問われるのは②の意味です。（実戦15）関連語「よろし」もよく問われます。また、「よろし」の同義語「けしうはあらず」（→P535）も問われます。
 関連 ：類義：よろし（形）「悪くはない。普通だ。まあまあだ。」 / 対義：わろし（形）「よくはない。」 / 対義：あし（形）「悪い。」
 例文 ：
 ①（対応訳語：①）
  風も吹かず、【よき】日出で来て、漕ぎ行く。 （土佐日記）
  → 風も吹かず、【よい】日和になってきて、漕ぎ進む。
 ②（対応訳語：②）
  【よき】人はあやしきことを語らず。 （徒然草）
  → 【身分が高く教養のある】人は不思議なことは語らない（ものだ）。
- 『論語』の「子は怪力乱神を語らず」に基づく言葉です。
 ③（対応訳語：関連語「よろし」）
  「【よろしき】者にやあらむ」とこそ思ひつれ、さらにこれはただ者にはあらず。 （落窪物語）
  → 「【普通の】者（＝ありふれた男）だろうか」と思ったが、まったくこの男は並たいていの者ではない。
 ④（対応訳語：関連語「よろし」）
  春ごとに咲くとて、桜を【よろしう】思ふ人やはある。 （枕草子）
  → 春が来るたびに咲くからといって、桜を【まあまあだと】思う人がいるだろうか（、いやいない）。
 ⑤（対応訳語：関連語「わろし」）
  友とするに【わろき】者、七つあり。 （徒然草）
  → 友とするのに【よくない】者が、七つある。

 ーーー

 解説 ：まず「奇し・怪し」と「賤し」の二通りの漢字を覚えましょう。驚きの声を表す感動詞「あや」から生まれた語で、基本の意は①です。貴族の目には庶民の様子が不思議なものに見えるので③・④の意が生じました。
 入試 ：入試で問われるのは②・③・④の意味です。とりわけ③・④はよくきかれます。（実戦16）①はまれにいい意味で使われます。「珍しくてすばらしい」という意味です。これが問われて得点できると優位に立てます。
 関連 ：派生：あやしむ・あやしがる（動四）「不思議に思う。」 / 類義：いやし（形）「身分が低い。」
 例文 ：
 ①（対応訳語：①）
  盗人【あやし】と思ひて、連子よりのぞきければ、若き女の死にて臥したるあり。 （今昔物語集）
  → 盗人は【不思議だ】と思って、連子窓からのぞいたところ、若い女で死んでよこたわっている人がいる。
- 場面は平安京の正門である羅城門の二階です。「連子」は、窓や戸に細かい角材や竹を一定の間隔で並べたものです。

  → 引き戸を荒々しくあけたてするのも、とても【けしからん】。
 ③（対応訳語：③）

  → 【身分が低い】下賤の者であるが、その言葉は聖人の教訓に一致している。
 ④（対応訳語：④）
  水無月のころ、【あやしき】家に夕顔の白く見えて、蚊遣火ふすぶるもあはれなり。 （徒然草）
  → 六月の頃、【粗末な】家に夕顔の花が白く見えて、蚊遣火がくすぶっているのも趣深い。
 ⑤（対応訳語：関連語「あやしむ」）

 訳語 ：①【大人らしい。大人びている。】 ②【年配だ。（年長で）主だっている。】 ③【（年配で）思慮分別がある。】
 ーーー
 核  ：「幼稚でない大人らしさ」
 解説 ：現代語の「おとなしい」（＝穏やかな性格）ではありません。名詞「大人」が形容詞化した語で「大人の要素を持っている」が基本の意なので、漢字で理解しましょう。年長、中心的な存在、分別があるということです。
 入試 ：どの意味も大切です。②は、実際の年齢はそれほど高くないときもあります。その集団の中で一番年長であるということです。これを「中年」と読むと、本文を誤読してしまいます。
 関連 ：名詞：おとな（名）「年長の者。主だった人。」 / 対義：いはけなし（形）（→No.82）
 例文 ：
 ①（対応訳語：①）
  今日よりは、【おとなしく】なり給へりや。 （源氏物語・紅葉賀）
  → 今日からは、【大人らしく】なられたか。
- 光源氏が、将来の妻として自邸に迎えたまだ幼げな紫の上に向かって、元日の朝に話しかけた言葉です。昔は数え年で年齢を数えていたため、正月一日が来ると一歳年をとることになりました。
 ②（対応訳語：②）
  心ばせある少将の尼、左衛門とてある【おとなしき】人、童ばかりぞとどめたりける。 （源氏物語・手習）
  → 気がきく少将の尼と、左衛門といって仕えている【年配の】女房と、童女の召使いだけを残しておいた。
 ③（対応訳語：③）
  さるべく【おとなしき】人々、何がしかがしといふいみじき源氏の武者たちをこそ、御送りに添へられたりけれ。 （大鏡）
  → しかるべく【思慮分別の】ある人々で、何の誰それというすぐれた源氏の武者たちを、お見送りのために添えられた。

 見出し：ゆかし （シク活用） ［重要度：★★★］
 訳語 ：①【見たい。聞きたい。知りたい。】
 ーーー
 核  ：「行ってみたいと心ひかれる」
 解説 ：四段動詞「行く」が形容詞化した語で、そちらへ行ってみたいと思うほど「心がひかれる」が基本の意です。心がひかれる対象に応じて「見たい」「聞きたい」「知りたい」などと訳し分けることが大切です。
 入試 ：選択式のときは、「〜たい」と訳されている選択肢を探しましょう。（実戦17）ただし、「〜たい」と訳されず「心ひかれる」と訳されていることもあるので注意しましょう。
 関連 ：派生：ゆかしげなり（形動）「見たそうだ。聞きたそうだ。知りたそうだ。」
 例文 ：
 ①（対応訳語：①）
  月かげ【ゆかしく】は、南面に池を掘れ。さてぞ見る。 （梁塵秘抄）
  → 月明かりが【見たい】ならば、屋敷の南正面に池を掘れ。そうして（池の水面に映る月を）見るのだ。
 ②（対応訳語：①）
  【ゆかしかり】しかど、神へ参るこそ本意なれと思ひて、山までは見ず。 （徒然草）
  → 【行ってみたかった】けれども、神社へ参拝するのが本来の目的なのだと思って、山の上までは見ない。
 ③（対応訳語：関連語「ゆかしげなり」）
  人の目をもおどろかし、心をもよろこばせ給ふ昔の世、【ゆかしげなり】。 （源氏物語・紅葉賀）
  → 人の目を見張らせ、心をもお喜ばせになる（源氏の）前世（はどのようなものであったか）を、（人々は）【知りたそうだ】。
- 当時の人々は、「因果応報」という仏教思想により、現世の幸・不幸は前世での行いの結果だと考えました。例文は、前世でどんな善行を積んだのか知りたいと語ることで、現世における光源氏のすばらしさを描き出しています。

[020]
 見出し：おぼつかなし （ク活用） ［重要度：★★☆］
 訳語 ：①【ぼんやりしている。はっきりしない。】 ②【気がかりだ。不安だ。】 ③【待ち遠しい。もどかしい。】
 ーーー
 核  ：「気になる」
 解説 ：「おぼ」は「おぼろ」から類推できるように、ぼんやりしていてつかみどころがない状態を表します。そういうはっきりしない状態から、②の不安な気持ちが生じ、また一方で③の期待する気持ちも生じてきます。
 入試 ：入試では②の意味がよく問われます。（実戦18）ただ、選択式のときは、より文脈に即してさまざまな言葉で訳されます。その時は、どうして気がかりなのか、気になってどういう思いなのかを考えて、適切な訳語を選びます。
 関連 ：派生：おぼめく（動四）「1 （よくわからず）まごつく。2 知らないふりをする。」 / 類義：こころもとなし（形）（→No.85） / 類義：うしろめたし（形） / 類義：そこはかとなし（形）「とりとめがない。はっきりしない。」
 例文 ：
 ①（対応訳語：①）
  明けぐれの空に、雪の光見えて【おぼつかなし】。 （源氏物語・若菜上）
  → 夜明けの薄暗い空に、雪明かりが（白く）見えて（辺りが）【ぼんやりしている】。
 ②（対応訳語：②）
  【おぼつかなき】もの。十二年の山ごもりの法師の女親。 （枕草子）
  → 【気がかりな】もの。十二年間の山籠りをしている僧の母親（の心）。
- 「山」は比叡山。比叡山延暦寺では、出家後十二年間、下山を許さず修行させたと言います。
 ③（対応訳語：③）
  いかでもの越しに対面して、【おぼつかなく】思ひつめたること、少しはるかさむ。 （伊勢物語）
  → なんとかして物隔てにでもお目にかかり、【待ち遠しく】思い重ねた心の中を、少し晴れやかにしたい。
- 「もの越し」とは几帳や簾を隔ててということで、貴族の男女がそういう姿で語り合う場面が平安時代の作品によく見られます。

 見出し：ありがたし 《有り難し》 （ク活用） ［重要度：★★☆］
 訳語 ：①【めったにない。】 ②【（めったにないほど）立派だ。すぐれている。】
 ーーー
 核  ：「有り＋難し」
 解説 ：現代語の感謝を表す言葉「ありがとう」と間違えないようにしましょう。ラ変動詞「有り」に形容詞「難し」が付いて生まれた語で、「存在することが難しい」が古語の基本の意味です。
 入試 ：訳語は「めったにない」を覚えておけば大丈夫です。（実戦11）ただし、現代語訳ばかりではなく、内容説明でもよく問われる語です。その時は「めったにない」ほどどうなのかを考えなければいけません。
 関連 ：なし
 例文 ：
 ①（対応訳語：①）
  【ありがたき】もの。舅にほめらるる婿。また、姑に思はるる嫁の君。 （枕草子）
  → 【めったにない】もの。舅（＝妻の父親）にほめられる婿。また、姑（＝夫の母親）に愛されるお嫁さん。
 ②（対応訳語：②）
  「物は、破れたる所ばかりを修理して用ゐる事ぞと、若き人に見ならはせて、心づけんためなり」と申されける、いと【ありがたかり】けり。 （徒然草）
  → 「物は、壊れた所だけを修理して使用するものだと、若い人に見習わせて、気づかせようとするためだ」と申されたのは、まことに【めったにないほど立派で】あった。

 見出し：めでたし （ク活用） ［重要度：★★★］
 訳語 ：①【すばらしい。立派だ。】
 ーーー
 核  ：「思いっきりほめたい！」
 解説 ：現代語の「めでたい」の意ではありません。下二段動詞「愛づ」（＝賞賛する）の連用形に形容詞「甚し」（＝はなはだしい）が付いた「めでいたし」から生まれた語で、「大いに賞賛すべき様子だ」の意を表します。
 入試 ：基本的な重要古語です。問われたら確実に得点しなければいけません。
 関連 ：動詞：めづ（動下二）（→No.54） / 派生：めづらし（形）「（めったになく）すばらしい。目新しい。」
 例文 ：
 ①（対応訳語：①）
  秋の月は、限りなく【めでたき】ものなり。 （徒然草）
  → 秋の月は、この上なく【すばらしい】ものである。
- 「雪月花（冬の雪・秋の月・春の桜）」は日本の四季を彩る代表的な美です。古文では、単に「月」とあるだけで秋の澄みきった月を言う場合があります。
 ②（対応訳語：①）
  大社を移して、【めでたく】造れり。 （徒然草）
  → 出雲大社の神の分霊を移して、【立派に】造営してある。
 ③（対応訳語：関連語「めづらし」）
  人の顔に、とり分きてよしと見ゆる所は、度ごとに見れども、あなをかし、【めづらし】とこそおぼゆれ。 （枕草子）
  → 人の顔で、特にいいと見える所は、（顔を合わせる）たびごとに見ても、ああ美しい、【すばらしい】と思われる。

 ーーー

 解説 ：期待や予想がはずれて残念な気持ちを表します。類義語「くやし」が自分の行為を悔やむ気持ちを表すのに対し、「くちをし」は恨みがましさを伴っていないので、「くやしい」と訳すのは避けた方が無難です。

 ①（対応訳語：①）

  → 見せようというものがあって、呼びにやった人が来ないのは、とても【残念だ】。
- 「見す」はサ行下二段動詞です。「見る」「見す」「見ゆ」（→P232）と正確に区別しましょう。

[024]
 見出し：うし 《憂し》 （ク活用） ［重要度：★★★］
 訳語 ：①【つらい。いやだ。】
 ーーー
 核  ：「憂鬱な気分」
 解説 ：物事が思いどおりにならず、憂鬱な気持ちを表します。恋愛や人間関係にまつわるつらさのほか、人が生きてゆく中で避けることのできない生の本質的なつらさやむなしさも表します。
 入試 ：「うし」はク活用形容詞なので、語幹は「う」です。これに感動詞「あな」が上に付くと「あなう」となります。「ああなんともつらい」という意味です。これが問われて得点できると優位に立てます。同様に「あなこころう」は「あな心憂」です。「あな心得」と勘違いしてはいけません。
 関連 ：複合：心憂し（形）「つらい。いやだ。」 / 類義：つらし（形）「薄情だ。むごい。」
 例文 ：
 ①（対応訳語：①）
  世を捨てて山に入る人山にてもなほ【憂き】時はいづちゆくらむ （古今和歌集）
  → 俗世間を捨てて（出家し）山に入る人は、山においてもやはり【つらい】時は（今度は）どこへ行くのだろう。
- 「山に入る」は山（山寺）に入って仏道の修行をすることを言います。
 ②（対応訳語：関連語「心憂し」）
  忠見、【心憂く】おぼえて、胸ふさがりて、不食の病つきてけり。 （沙石集）
  → 忠見は、【つらく】思われて、胸がつまって、食べ物がのどを通らない病気になってしまった。
- 壬生忠見が歌合（＝左右の組に分かれて歌の優劣を競う行事）で負けになった後のありさまです。平安時代の歌人がいかに和歌に執着していたかがわかる説話です。
 ③（対応訳語：関連語「つらし」）
  いとは【つらく】見ゆれど、志はせむとす。 （土佐日記）
  → ひどく【薄情に】思われるが、謝礼はしようと思う。
- 「つらし」は「つらい」「堪え難い」の意もありますが、「（つらくなるほど相手が）薄情だ」と相手の冷たい態度や仕打ちを「むごい」と非難する気持ちを表す意が重要です。

[025]
 見出し：わびし 《侘びし》 （シク活用） ［重要度：★★★］
 訳語 ：①【つらい。困ったことだ。】 ②【興ざめだ。もの足りない。】
 ーーー
 核  ：「やりきれない」
 解説 ：現代語「わびしい」の落ちぶれたイメージにとらわれないようにしましょう。上二段動詞「侘ぶ」（＝思うようにならず落胆し、嘆く）の形容詞化した語で、物事が思うようにならず「やりきれない」の意が基本です。
 入試 ：現代語訳でも心情説明でもよく問われます。「やりきれない」と押さえておけば大丈夫です。選択式で「やりきれない」と訳されていないときは、その言い換えの訳を探します。記述式のときはともかくKEYの「やりきれない」で訳します。
 関連 ：動詞：わぶ（動上二）「1 やりきれなく思う。困る。2 （つらいと）嘆く。3 〔動詞の連用形に付いて〕〜しかねる。」
 例文 ：
 ①（対応訳語：①）
  すべてかれに【わびしき】めな見せそ。 （大和物語）
  → 万事この女に【つらい】目を見させるな。
- 「な〜そ」（→P66）は禁止を表す呼応表現です。
 ②（対応訳語：②）
  前栽の草木まで、心のままならず作りなせるは、見る目も苦しく、いと【わびし】。 （徒然草）
  → 庭の植え込みの草や木までも、その自然の趣のままの姿でなく意図的に作り上げているのは、見た目にも不愉快で、たいへん【興ざめだ】。
- 「興ざめ」とは、それまで感じていた面白みや愉快さが消えることを言います。
 ③（対応訳語：関連語「わぶ」）
  つれづれ【わぶる】人は、いかなる心ならん。まぎるる方なく、ただ一人あるのみこそよけれ。 （徒然草）
  → することのない状態を【つらいと嘆く】人は、どのような心なのだろう。（事にも人にも）まぎれることなく、たった一人でいることこそよいのだ。
