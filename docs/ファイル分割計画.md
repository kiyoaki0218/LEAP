# index.html ファイル分割計画（Stage 2 以降）

`index.html`（HTML/CSS/JS 集約）を、ビルド工程を入れずに責務ごとのファイルへ段階的に分割するための作業手順書です。

- 対象: このリポジトリの `index.html`
- 関連: `SERVICE.md`（サービス仕様）、`AGENTS.md`（更新ルール）
- 最終更新: 2026-11-22（Stage 2 = `js/core.js` 分離の完了時点）

---

## 0. 前提と守るべき制約

| 項目 | 内容 |
|---|---|
| ビルド | 導入しない。`<script>` / `<link>` の直接読み込みのみ |
| JS の形式 | **クラシックスクリプトのまま**（`type="module"` にしない） |
| 理由 | マークアップの `onclick="..."` がグローバル関数を直接呼んでいるため。モジュール化すると全ハンドラが動かなくなる |
| マークアップ | **分割しない**。`fetch` + 注入はビルド無しでは初回描画・オフライン動作を壊す |
| 改名 | しない。既存の関数名・変数名はそのまま移す（改名は分割完了後の別タスク） |
| `patches/` | 再実行しない（過去改修の記録。二重適用になる） |
| 動作 | localStorage キー・データ移行・PWA/SW・Supabase 任意連携を一切変えない |

### 必須の更新（毎 Stage 共通）

1. `sw.js` の `ASSETS` に新規ファイルを追加し、`CACHE` を +1
2. `index.html` 冒頭の `APP_VER` を更新

## 2. グローバル依存の整理方針

クラシックスクリプトを複数ファイルに分けると、**トップレベルの `const` / `let` / `function` は全ファイルで共有される**（同一のグローバルレキシカル環境）。これを踏まえたルール:

1. **トップレベルの宣言名はリポジトリ全体で一意**にする。同名 `const` を 2 ファイルに置くと `SyntaxError: Identifier 'X' has already been declared` で**アプリ全体が起動しなくなる**。
2. **トップレベルで他ファイルの状態を読まない**。初期化は `js/init.js` の `DOMContentLoaded` に集約する。例外は「データ定数の複製」（`LEAP_SOURCE = typeof LEAP_WORDS_DATA ...`）のみ。
3. **相互参照する塊は同じファイルに置く**。代表例:
   - `LEAP_PARTS` → `PARTS` → `ALL_WORDS` → `applySubject()`（同一ファイル内で直後に参照している）
   - `SCREENS` → `navigate()`
   - `STORAGE_KEY` → `userData` → `loadUserData()`
4. **`function` 宣言は呼び出し時に解決される**ため、ファイル間の読み込み順は「呼び出し時参照」であれば問題にならない。順序が効くのは**トップレベル即時実行**だけ。
5. 各ファイルの先頭に `/* provides: ... / requires: ... */` を置き、依存を目視できるようにする。
6. 新規コードは既存と同じグローバル関数で書く（インライン `onclick` から呼ぶため）。どうしても閉じたい処理だけ IIFE にし、公開する名前を明示する。

### 2.1 事故防止チェック（任意・ビルドではない）

`patches/check_globals.js`（Node 標準モジュールのみ、手動実行）を用意する場合の仕様:

- `js/*.js` を走査し、`^\s*(function|const|let|var)\s+(\w+)` の**重複宣言**を報告
- `index.html` の `onclick="NAME(` / `oninput="NAME(` を抽出し、どのファイルにも宣言が無い名前を報告
- 出力は警告のみ。ファイルは書き換えない（`patches/` の既存スクリプトとは別物）

## 6. 既知の落とし穴

| 症状 | 原因と対処 |
|---|---|
| `Identifier 'X' has already been declared` で全画面が白 | トップレベル宣言の重複。`js/*.js` 全体で名前を検索して一意にする |
| `Cannot access 'X' before initialization` | 別ファイルの `const` をトップレベルで即時参照している。`init.js` の `DOMContentLoaded` に移す |
| ボタンを押しても何も起きない | `onclick` の関数が未定義（読み込み漏れ・改名）。`ASSETS` と `<script src>` の両方を確認 |
| オフラインで真っ白 | 新ファイルが `sw.js` の `ASSETS` に入っていない、または `CACHE` を上げていない |
| ダークモードの配色が一部戻らない | `assets/css/app.css` を触った場合は `APP_VER` / `CACHE` を上げる（SW は静的アセットをキャッシュ優先で返すため） |
| 辞典が空（「単語データが読み込まれていません」） | `openDictionary()` を経由せず `navigate('screen-dictionary')` だけを呼んでいる。描画は `openDictionary()` が行う |
